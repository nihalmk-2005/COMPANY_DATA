This project is created using **Microsoft Power BI** to explore data, identify useful insights, and present information through interactive visualizations and reports.

The project demonstrates practical data analytics and business intelligence skills.

## 🎯 Project Objectives

* Analyze data and identify meaningful insights.
* Create interactive charts and visualizations.
* Understand trends and patterns in the data.
* Support data-driven decision-making.
* Present findings through a Power BI report.

## 🛠️ Tools & Technologies

* **Microsoft Power BI** — Data visualization and reporting
* **Power Query** — Data cleaning and transformation
* **DAX** — Calculations and measures
* **Data Modeling** — Organizing relationships between tables

1. Download the `.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. Explore the report and its visualizations.
